# 西财课表导入

## 已实现的流程

课表右上角下载图标 → 校外 WebVPN / 校内教务 → 用户自行登录 → 打开个人课表查询并选学期 → 读取 → 勾选预览 → 合并保存。空课表也有入口。

网页版不嵌入学校登录页，可选择本机保存的课表 HTML，在本机解析、预览、导入。浏览器运行检查使用 `tests/fixtures/swufe.html`，没有上传 HTML 的接口。

## 教学班与上课安排

- `Course` 是作业关联的课程；`sessions` 是课表上的上课安排。
- 有 `source.classId` 时，使用学校、学期和教务 `jxb_id` 精确匹配。周一与周五、调课换教室、分阶段换教师可以共享同一个 Course。完整原始教学班编号保存在 source，页面路由使用稳定本地 id。
- 每个 session 单独保存 `weeks` 数组、地点和教师。Course.weeks 是展示摘要，不用它代替每次上课的周次来筛选课表。
- 缺少教学班编号时，按这份个人课表的课名、教师归组为待确认本地课程，不宣称已匹配其他同学。完全相同的课表重复导入可去重；缺少编号且安排改变时保守保留为新课程。
- DOM 暂存课程随后取得真实教学班编号时，不凭相同课名强行合并，用户可取消勾选或删除重复本地课程。共享功能接入前，应优先实测原始接口覆盖率。

## 读取方式与限制

`src/lib/swufe/browser.ts` 仅在个人课表查询页安装桥接，观察学校自身发出的 `/kbcx/xskbcx_cxXsgrkb.html` 响应，缓存白名单课表字段。用户点击读取时才回传给 App。既不发起代登录请求，也不读取请求体、账号密码、cookie 或响应中的学生资料。

原始接口的字段依据用户保存的学校 `xskbcx.js`：`kbList`、`jxb_id`、`jxbmc`、`kch`、`kcmc`、`xqj`、`jcs` / `jc`、`zcd`、`xm`、`cdmc` 等。学期的内部取值为 3 / 12 / 16，对应界面的 1 / 2 / 3。

Android 的早期脚本注入可能错过首次查询；加载结束会再次安装，之后在学校页面点击“查询”可捕获。尚未捕获时只回传 `#table1.outerHTML`，限定至第一个表格，不处理重复的 table2。HTML 里只有两门调课课程保留了教学班编号，不能由此推断其他课程的编号。

桥接拒绝乱序旧响应，检查选择的学期与显示的课表是否一致，查询中禁止读取。App 检查消息所在学校页面、请求编号和字段格式。缺失或未知周次直接报错，不默认为全学期，也不部分落库。

1.0.1 修复安卓消息源兼容：`react-native-webview@14.0.1` 在支持 WebMessageListener 的 Android 上把消息源设为 sourceOrigin（例如 `https://webvpn.swufe.edu.cn`），并非完整页面 URL。现在验证消息与真实来源同源，并使用消息中的完整 href 判定课表路径；仍拒绝跨域、不同协议/端口和含凭据的 URL。原来的完整 URL 相等检查会丢弃正常探针，导致按钮一直灰色。

读取按钮现在仅在读取/保存期间禁用，可以主动检查当前页面，不依赖后台探针先成功回报。真正读取时仍检查课表 DOM、学期、消息源和请求编号；未就绪会显示具体提示。

## 保存、更新与撤销

默认合并，不删除原有课程和作业。相同学校、学期和教学班编号的课程更新安排，并保留原本地 id、配色、人数，原作业继续关联原 id。预览可逐门取消勾选，并标明新增 / 更新。导入先等待本地写入成功再提示完成；写入失败保留原课表和预览，可直接重试。所有快照按顺序写入，防止较慢的旧写入覆盖新导入。

一次导入后提供撤销；只撤回本次应用的课程变更，不用全库快照覆盖之后的操作。新导入课程如果已经添加了作业，撤销时保留该课程，避免产生悬空作业。

沿用 `store.v1`，读取旧版 weeks 单对象时转换成数组，并为各 session 补周次，原课程 id 不变。保留原 profile、settings 和 homework。主题仍单独保存。

不同学期的课程分开保存，课表可切换学期，也可切换手动 / 演示课程；导入后默认展示导入的学期。开学日期可选，必须是第一周的周一；按本地日历计算当前周。未填写时展示按周查看，不冒充真实当前周。

## 登录会话与原生配置

WebView 使用无痕模式、关闭表单保存和缓存。重新登录 / 切换校内外模式会重建 WebView；Android 库会在创建无痕 WebView 时清除 cookie。不同学校域的网页存储行为仍需实机验证，App 不把 cookie 或网页存储复制进自己的 store。

`plugins/withSwufeCleartext.js` 在 prebuild 时生成网络安全 XML 并配置 manifest，正式包只放行 `jwxt.swufe.edu.cn` 的 HTTP；debug 资源覆盖保留开发时连接局域网 Metro 的 HTTP 能力。不要手工修改生成的 android 目录。主要目标为安卓，iOS 的校内 HTTP 链路未验收。

## 验证

```bash
npm ci
npm test
npx tsc --noEmit
npx expo export --platform web
npx expo prebuild --platform android --no-install
```

测试 fixture 来自交付包已脱敏样本，仅保留 table1 / table2，姓名 / 学号为张三 / 00000000。原 expected.json 的“形势与政策III”漏掉单周，测试明确纠正为 7、9、11、13 周。

30 项自动测试覆盖整份课表逐项对照、同班多时间 / 多地点 / 多教师、不同班不混合、单双周、旧数据迁移、重复导入保留关联、不同学期分隔、桥接白名单、乱序响应、错学期拦截、写入顺序与保存失败重试，并通过真实 Expo config plugin 生成和解析原生 XML，检查正式包域名范围与显式 includeSubdomains 属性。另覆盖安卓 sourceOrigin 消息、旧版完整 URL 消息、校内 HTTP、跨源拦截及未就绪页面的错误反馈。接口响应测试使用构造数据，不代表已验证学校在线响应。

浏览器检查覆盖手机宽度的预览、勾选、保存失败后重试、导入、撤销、重复导入、成功后立即刷新恢复、编辑第二个安排且不改变第一个安排；发布一条概率论作业后，从周一和周五课块进入同一课程，都能看到这条作业。另验证暮色主题、从预览返回网页，以及删空当前学期后仍可切换到原有手动课程。Android prebuild 检查 XML 和 manifest，网页与 Android JS 打包通过。GitHub Actions 生成安装包并验证签名；手机真实登录由用户收到 APK 后验证，步骤见 [ANDROID_TEST.md](./ANDROID_TEST.md)。

仓库原本未配置 lint。使用临时的 Expo 默认配置运行检查时，原有动画、refs 和 Date.now 写法存在 React Compiler lint 错误；本次对照 HEAD 从 107 项降至 75 项，没有新增错误。检查用的 lint 依赖和配置未写入改动内容。
