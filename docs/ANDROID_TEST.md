# 安卓课表导入测试

## 安装

使用这次功能分支构建的 APK，支持 arm64 安卓手机。安装包采用项目现有的开发签名，供本轮测试；尚未配置正式发布签名。

当前合并版为 1.0.2（versionCode 3），保留 1.0.1 对“读取课表并预览”一直灰色的修复，并合入 main 的界面线程翻页手势。按钮可以主动读取；页面未就绪时显示提示，正在读取或保存时暂时禁用。新增的 gesture-handler、Reanimated 和 Worklets 原生模块已包含在本次 APK 中，需要更新安装后测试。

如果系统提示签名不兼容，请先保留原 App 和数据，不要直接卸载；记录提示以便排查。单纯更新安装通常会保留本地数据。

## 校外登录并导入

1. 打开“课表”，点右上角下载图标，选择“校外”。
2. 在学校网页里自行登录校园账号；密码不需要发给开发者。
3. 在 WebVPN 门户打开“教务处 / 本科新系统”，使用教务密码完成第二次登录。两套密码可能不同。
4. 进入“个人课表查询”，选择正确学年学期，点学校页面上的“查询”。请在本次打开后重新查询一次，以便捕获学校返回的教学班编号。
5. 等课程显示后点“读取课表并预览”。确认学期、教师、时间、地点、周次，勾选后导入。可填写第一周周一的日期，自动计算当前周。

## 本次重点检查

- 底部三页均可左右滑动翻页；在课表页先向下滑、保持手指不松开再横滑，仍能接管翻页。斜着向下滑时不应误翻，点底部标签仍可切换。
- 导入课表后重复上述手势，确认课表纵向滚动、课程点击、学期和周次选择，以及打开导入入口均正常。
- 概率论周一与周五应归在同一课程；预览是否标明“教学班已识别”？如果仍为“教学班待确认”，请返回网页再查询一次。
- 数字政府第 6 周应显示周二讲座，其余对应周次显示周四；不能同时套用同一组周次。
- 形势与政策只在 7、9、11、13 周出现。
- 创新程序设计实践在不同周次显示对应教师；接口返回相同教学班编号时应归入同一课程。
- 发布一条概率论作业，从周一和周五课块进去都能看到；重新导入后这条作业还在。
- 完全关闭后重新打开，导入结果、学期和开学日期仍保留。
- 再导入同一学期，不应重复增加已识别的教学班；点击“撤销”可撤回本次导入。
- 点“清除会话并重新登录”，确认重新进入登录流程；换账号后应读取新账号的课表。

如果在校内网络，切换“校内”后重复登录、读取，检查正式 APK 中 HTTP 教务页面能否正常打开。

## 反馈

遇到问题时，记录手机型号、Android 版本、卡在哪一步、页面提示和预览中“教学班已识别 / 待确认”的情况即可。不要发送账号密码、验证码或登录 cookie。

当前没有多人共享后端和系统通知；本轮检查聚焦学校登录、课表导入和本地作业关联。
