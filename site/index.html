我们不碰你的隐私

  • 只用邮箱注册，不要学号，不要姓名。
  • 教务的账号密码只在学校自己的登录页里输入，app 读不到，也不保存。
  • 导入课表时只上传课程安排（哪门课、几点、在哪），别的信息在手机上就丢掉了。
  • 代码全部公开在 GitHub，谁都可以检查。

安装前看一眼

  • 目前只有安卓版，支持 64 位手机，近几年买的基本都是。
  • 下载后打开安装包，系统提示「未知来源」时选允许。
  • 想让提醒准时：在 app 的「我的 → 提醒可能不准时」里按提示设置一下，还可以发一条测试提醒看看。

下载慢或者打不开的话，可以到 GitHub 的发布页手动下载。
