# 作业

西南财经大学同学共享作业和截止日期的安卓 App。一人上传，同课的同学都能看到，并按截止时间提醒。

当前是前端与本地存储版本，初次打开使用演示数据，还没有接后端和 App 账号登录。已接入教务课表导入页面：学校网页内自行登录 → 读取 → 预览勾选 → 合并保存；手机真实登录链路仍待实测。作业共享和系统通知尚未接入。

课表导入说明与验证方式见 [docs/SWUFE_IMPORT.md](docs/SWUFE_IMPORT.md)。网页预览可选择已保存的课表 HTML，文件在本机处理。

## 设计

- 安静、内敛、简洁。标题用宋体，正文用黑体，紧凑列表。
- 两个主题，在"我的 → 外观"切换：默认"纸页"（暖白纸色、白卡片细边框、陶土色点缀）；"暮色"（紫灰渐变背景、半透明毛玻璃卡片，色调随时间微调）。
- 首页标题随时间换一句话（今天 / 傍晚好 / 夜深了）。
- 强调色只用低饱和雾蓝，临期作业用砖红。

## 运行

```bash
npm install
npx expo start
```

- 手机：安装 Expo Go，扫终端里的二维码。
- 电脑浏览器：在终端按 `w`。

## 目录

```
src/app/          页面（Expo Router）
  (tabs)/         作业、课表、我的
  homework/[id]   作业详情
  course/[id]     课程详情
  upload          上传作业
  add-course      添加课程（手动，演示版匹配）
  import/swufe    教务导入与预览
src/theme/        配色和字体
src/data/         演示数据和共享状态
src/components/   通用组件
src/lib/swufe/    学校课表解析和 WebView 桥接
tests/           脱敏样本与导入回归测试
```
