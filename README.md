# 作业

西南财经大学同学共享作业和截止日期的安卓 App。一人上传，同课的同学都能看到，并按截止时间提醒。

当前是第一版界面原型，全部使用演示数据，还没有接后端和登录。

## 设计

- 安静、内敛、简洁。标题用宋体，正文用黑体，紧凑列表。
- 主题随时间变化：白天（6:00–16:30）米白，傍晚（16:30–19:00）暮色渐变加毛玻璃，夜晚（19:00–6:00）午夜蓝。
- 打开 App 时，先显示上次看到的主题，停顿 1 秒，再用 3 秒从上往下过渡到当前主题。正在使用时到点，等用户停手后再过渡；打开上传、添加课程等页面时不切换。
- 强调色只用低饱和雾蓝，临期作业用砖红。

## 运行

```bash
npm install
npx expo start
```

- 手机：安装 Expo Go，扫终端里的二维码。
- 电脑浏览器：在终端按 `w`。

## 目录

```
src/app/          页面（Expo Router）
  (tabs)/         作业、课表、我的
  homework/[id]   作业详情
  course/[id]     课程详情
  upload          上传作业
  add-course      添加课程（手动，演示版匹配）
src/theme/        配色和随时间变化的主题
src/data/         演示数据和共享状态
src/components/   通用组件
```
